# 📚 Arquivos de UX

Uma aplicação web interativa desenvolvida em **Next.js** e **TypeScript** para consulta, estudo e acompanhamento de termos fundamentais de Experiência do Usuário (UX).

---

## ✨ Funcionalidades

* **🔍 Busca Instantânea:** Pesquise rapidamente por nome de termo ou definição na barra de pesquisa principal.
* **🏷️ Filtros por Categoria:** Navegue por áreas específicas como:
  * Pesquisa
  * Arquitetura da Informação
  * Interação
  * Prototipagem
  * Estratégia
  * Times & Métodos
  * Design Visual
* **📊 Acompanhamento de Progresso:** Visualize em tempo real o contador de termos vistos versus o total, além do filtro para focar apenas nos itens marcados para revisão.
* **💾 Progresso Persistente:** O seu progresso de leitura e estudos é salvo automaticamente no `localStorage` do navegador.

---

## 🚀 Tecnologias Utilizadas

* **[Next.js](https://nextjs.org/)** — Framework React para produção
* **[React](https://react.dev/)** — Biblioteca para construção de interfaces
* **[TypeScript](https://www.typescriptlang.org/)** — Superset JavaScript tipado
* **Tailwind CSS** — Estilização moderna e responsiva
